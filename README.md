# Loja Online

Projeto de e-comerce desesnvolvido na diciplina git, Agile & Dev culture.

## Como rodar 

git clone https://github.com/guilhermeRikesilva/Loja--Online-EAD.git
cd Loja--Online-EAD
npm install
npm start

## Estrutura

- /src - Código da aplicação 
- /tests - testes automatizados
- .github/workflow - pipeline de CI
